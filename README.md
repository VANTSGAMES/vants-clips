# VANTS GAMES · Clips destacados
Almacén público de los clips que los jugadores destacan desde la arena (vants.vants.workers.dev/clips). Gestión automática vía API.

## Agentes: el cuartel es flask-Agents

**Anuncio del ecosistema:** el cuartel de los agentes es
[`VANTSNET/flask-Agents`](https://github.com/VANTSNET/flask-Agents): ahí vive
el código de todos los agentes, los viejos y los nuevos, y su web es
https://vants-ai.vercel.app/. Este repo no guarda código de agentes; si el
cuartel o la plataforma lo necesitan, se conectan como clientes (VANTS-BUS o
colas de Neon).
